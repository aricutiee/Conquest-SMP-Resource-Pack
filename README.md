# Conquest SMP Resource Pack

Java 21 asset generator for the Conquest tab logo, rank badges, sidebar glyphs and crown assets. Run `gradlew.bat build` or `./gradlew build`. Output: `build/ConquestSMP-resource-pack.zip`. This is the companion pack for Conquest SMP Mass. Deploy the generated ZIP through the plugin resource-pack hosting configuration.

Warlord theme: The Dread by Kevin MacLeod, CC BY 4.0. The first 13 seconds are edited with fades. Attribution and source links are in design/audio/CREDITS.txt and included in the generated pack.
